**[IncidentIQ](https://github.com/prachics/incidentiq)**: agentic AI platform for production incident support. A LangGraph agent with hybrid retrieval (pgvector + Postgres full-text), read-only diagnostic tools, persisted investigation state, and approval-gated write actions, all on a FastAPI backend. Its evaluation harness publishes real results, including ones still below target. Retrieval measures Recall@5 0.80 and MRR 0.92. The approval API, frontend, and tracing are in progress.
